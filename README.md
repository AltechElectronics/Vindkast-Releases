# Vindkast Releases

Published installers for **Vindkast**, a free Windows ASIO driver that plays Qobuz or any other
ASIO-capable player on a Linn DS/DSM, bit-perfect, over the Songcast protocol. It can also send to
AirPlay receivers.

## Download

Get the latest installer from the
[Releases page](https://github.com/AltechElectronics/Vindkast-Releases/releases/latest):
download `Vindkast-Setup-<version>.exe` and run it.

## Getting started

1. Run the installer, and start the tray helper when it offers to.
2. Right-click the Vindkast tray icon and pick your receiver.
3. Select **Vindkast** as the output device in your player.

## Requirements

64-bit Windows 10 or 11. Nothing else needs to be installed.
